# Weights / 权重

The trained weight is intentionally withheld from this public repository until the exact licensing and redistribution terms of all three source datasets are matched to the local copies.

本公开仓库暂不提供训练权重，待三个数据集的实际本地版本与许可证及再分发条款逐一确认后再决定。

The locally prepared release candidate has been privacy-sanitized and load-tested, but it is not uploaded by this commit.

本地发布候选已完成隐私清理并通过加载验证，但本次提交不上传该文件。
